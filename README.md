# 離淵紀 v007 Playtest

Godot Web build for the v007 ARPG prototype.

## Controls

- Hold/drag LMB: move
- LMB on enemy: chase and cast Double
- RMB: place orb
- 1: Heavy
- 2: Claw
- Hold 3: Beam
- 4: Needle
- Space: dodge
- G: GM hit areas
- R: restart

Controller test mapping follows the in-game UI.

## Build Notes

- Main scene: `res://scenes/v007_prototype/V007ArpgPrototype.tscn`
- Chinese font included: `NotoSansTC`

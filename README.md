# Liyuan Ji v007 Playtest

Godot Web build for the v007 ARPG prototype.

## Controls

- Hold/drag LMB: move
- LMB on enemy / L: Slash
- Hold RMB / 6: Infinite Slash
- 1: Heavy Slash
- 2: Crescent Slash
- 3: Full Moon Slash
- 4: Flying Circle Slash
- Q / L1: Heal
- Space: dodge
- G: GM hit areas
- R: restart

Controller test mapping follows the in-game UI.

- Main scene: `res://scenes/v007_prototype/V007ArpgPrototype.tscn`
